## 📝 Important Notes

### Roll Number Format:
```
✅ 3-digit: 001, 002, 003... (নতুন batches)
✅ 6-digit: 262601, 262602... (পুরাতন batches)
✅ Custom: যেকোনো number manual entry করতে পারবেন
```

### Student ID Format:
```
Pattern: UCC-{BATCH}-{ROLL}

Examples:
- UCC-HUMBN2-001         (Humanities BN 2)
- UCC-HUMBN12026-262676  (Humnities BN 1)
- UCC-MEDICA2026A-015    (Medical A)
```

### Discount Calculation:
```
Percentage Example:
   Course Fee: ৳15,000
   Discount: 10% 
   = ৳1,500 discount
   Net Fee: ৳13,500

Fixed Amount Example:
   Course Fee: ৳15,000
   Discount: ৳2,000
   Net Fee: ৳13,000
```
